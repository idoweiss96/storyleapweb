# הטיימר החזותי — Visual Timer

**נתיב:** `/activities/visual-timer`
**מקור במיפוי:** גל 1 · אשכול "הכנה, שגרה ומעברים" · מנוע רצף · ללא רגישות
**הערה במיפוי:** "קל לבנייה אך בידול מוגבל לבד"

---

## מה זה

טבעת צבע שמתכווצת לאורך הזמן שנבחר. הילד רואה כמה נשאר במקום לספור דקות.

**זו הפעילות הראשונה בתיקייה בלי פלט להדפסה**, והראשונה שרצה על שעון
ולא על לחיצות.

---

## הבידול שהמיפוי מבקש

טיימר לבדו הוא מוצר מדף — יש אלף כאלה. מה שמצדיק אותו כאן זה
**שהוא תמיד מחובר לדבר בשם**: "עוד קצת משחק", "זמן מסך", "לחכות לתור".

ילד שמתווכח עם מספר מנהל שיחה אחת; ילד שרואה צבע נעלם מ"עוד קצת משחק"
מנהל שיחה אחרת לגמרי.

הטיפ להורה מוסיף את הכלל שהופך אותו לעובד: **להראות את הטיימר לפני
שמתחילים, לא ברגע שצריך להפסיק.** ילד שראה את העיגול מלא בהתחלה
מבין שהסוף נקבע מראש — ולא שההורה החליט לעצור כי נמאס לו.

---

## מימוש

### הזמן נמדד מול שעון הקיר, לא בספירה

```js
deadline = Date.now() + seconds * 1000
// כל 200ms:
left = Math.max(0, Math.round((deadline - Date.now()) / 1000))
```

ולא `remaining -= 1` בכל טיק. שתי סיבות:

- **`setInterval` נסחף** — הוא לא מדויק, והשגיאה מצטברת לאורך 15 דקות
- **טאב ברקע נחנק** — דפדפנים מאטים טיימרים בלשוניות לא פעילות עד
  לפעם בשנייה או פחות. ספירה הייתה מפגרת; חישוב מול `Date.now()`
  מתקן את עצמו ברגע שחוזרים ללשונית

ה-`interval` רץ כל 200ms ולא כל שנייה, כדי שהתצוגה תתעדכן מיד
כשחוזרים ללשונית ולא אחרי עד שנייה שלמה.

### הטבעת

מצוירת כ-`stroke-dasharray` + `strokeDashoffset` על מעגל אחד,
ולא כקשת עם `A`. זה מונע את מקרה הקצה של קשת ב-100% בדיוק,
שבו `large-arc-flag` הופך את הצורה על עצמה.

הסיבוב `-90°` מזיז את נקודת ההתחלה לשעה 12.

### ניקוי

ה-`interval` נשמר ב-`ref` ומנוקה גם ב-`useEffect` וגם בכל פעולה
שמפסיקה את הטיימר — אחרת טיימר שרץ ברקע ממשיך לעדכן state
אחרי שהרכיב ירד.

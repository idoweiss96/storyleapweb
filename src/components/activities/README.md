# מקום הפעילויות — Activities

התיקייה הזו מכילה את כל הפעילויות והמשחקים החינמיים של StoryLeap.
כל פעילות יושבת בתת-תיקייה משלה, עם README משלה שמסביר איך היא עובדת.

---

## העיקרון המנחה

**נבנה פעם אחת, עובד תמיד.**

כל פעילות כאן חייבת לעמוד בשלושת התנאים האלה:

| תנאי | למה |
|---|---|
| **אפס קריאות AI** | הפעילות לא שולחת בקשה לשום מודל, לא בזמן טעינה ולא תוך כדי משחק |
| **אפס backend** | אין קריאות רשת, אין entities, אין functions. הכול רץ בדפדפן |
| **תוכן כתוב מראש** | כל טקסט שהילד רואה נכתב ידנית לקובץ תוכן ונשמר בגיט |

התוצאה: הפעילויות עובדות אופליין, לא עולות כסף לכל שימוש, לא נשברות כשמודל מתעדכן,
ולא דורשות הרשמה. הן גם ניתנות לבדיקה מלאה — אותה קלט תמיד נותן אותו פלט.

זה **בכוונה** ההפך ממנוע הסיפורים בתשלום, שכן מייצר תוכן פר-ילד.

## מאיפה הפעילויות מגיעות

הפעילויות נבחרות מתוך `StoryLeap_Professional_Tools_Map_v2` — מיפוי של 60 כלים מקצועיים
(`02_Product / Professional_Tools_Suite`). כרגע אנחנו בונים מ**גל 0** בלבד, ומתוכו רק
כלים שעומדים בעיקרון למעלה.

מתוך 13 כלי גל 0, **12 עומדים בקריטריון**. היחיד שלא הוא *סיפור חברתי*, שרץ על
מנוע הסיפור/תרחיש ולכן דורש AI — הוא שייך למוצר בתשלום, לא לכאן.

12 הכלים הנותרים מתחלקים לארבעה מנועים:

| מנוע | כלים בגל 0 | סטטוס |
|---|---|---|
| כרטיסים | גלגל רגשות, קלפי רגשות, קלפי חוזקות, Coping Cards, לוח בחירה, כרטיס בקשת הפסקה | 2 מתוך 6 נבנו |
| סולם/מדידה | מד חום רגשי, Emotion Check-in | טרם |
| רצף וסדר יום | לוח סדר יום חזותי, First–Then | טרם |
| קנבס יצירתי | ציור הרגש, מפת גוף | טרם |

## ארבע נקודות החיווט

כל פעילות מחוברת לאתר בארבעה מקומות. חשוב לעבור על כולם, אחרת הפעילות קיימת אבל לא נגישה:

1. **`src/components/activities/<שם>/`** — הרכיב וקובץ התוכן
2. **`src/pages/Activity<שם>.jsx`** — עמוד דק שעוטף את הרכיב
3. **`src/App.jsx`** — `import` + `<Route path="/activities/<שם>" …>`
4. **`src/pages/Activities.jsx`** — רשומה במערך `GAMES`, כדי שהכרטיס יופיע ב-hub

> `src/pages.config.js` הוא קובץ שנוצר אוטומטית. **לא נוגעים בו** — הנתיבים של הפעילויות
> מוגדרים ידנית ב-`App.jsx`, כמו שאר הנתיבים המותאמים באתר.

## איך מוסיפים פעילות חדשה

### 1. קובץ תוכן

`src/components/activities/<שם>/<שם>Content.js`. שלושה ייצואים קבועים:

```js
export const <DECK> = [ … ];   // הנתונים של הפעילות (קלפים, רגשות, שלבים)
export const UI = { he: {…}, en: {…} };     // כל מחרוזת שמוצגת למשתמש
export const META = { he: {…}, en: {…} };   // title + description ל-SEO
```

כל פריט בחפיסה נושא את הטקסט שלו בשתי השפות, כדי שהוספת פריט תהיה שינוי במקום אחד:

```js
{
  id: 'brave',
  emoji: '🦁',
  he: { label: 'אני אמיץ/ה גם כשמפחיד', prompt: 'מה עשית למרות שקצת פחדת?' },
  en: { label: 'I am brave even when it is scary', prompt: 'What did you do even though you were a bit scared?' },
}
```

### 2. הרכיב

מקבל `lang` כ-prop (`'he'` או `'en'`) — הוא לא קורא ל-`useLanguage` בעצמו.
זה משאיר אותו נקי מהקשר, וקל לבדיקה ולשימוש חוזר.

```jsx
export default function MyActivity({ lang = 'he' }) {
  const copy = UI[lang] || UI.he;
  …
}
```

### 3. העמוד

העמוד הוא זה שקורא ל-`useLanguage`, ומעביר את התוצאה פנימה:

```jsx
const { lang } = useLanguage();
const isHe = lang === 'he';
…
<MyActivity lang={isHe ? 'he' : 'en'} />
```

### 4. חיווט

`App.jsx` + `GAMES` ב-`Activities.jsx`. ראו למעלה.

### 5. README

תת-תיקייה בלי README היא תיקייה שאף אחד לא יבין בעוד חצי שנה. ראו את שתי הקיימות כדוגמה.

## קונבנציות

### שפה

דו-לשוני תמיד, עמוד אחד לשתי השפות. מתג השפה בהדר מחליף בין `he` ל-`en`
ללא ניווט. ה-RTL מטופל ברמת ה-`Layout` (`dir` על ה-shell), אז אין צורך ב-`dir`
ברכיב עצמו — אבל **כן** צריך להשתמש ב-`inset-inline-start/end` במקום `left/right`
לכל מיקום אבסולוטי, אחרת פינות וסמלים יקפצו לצד הלא נכון באנגלית.

### עיצוב

הפלטה של המותג:

| תפקיד | ערך |
|---|---|
| ורוד | `#FF6FB5` |
| תכלת | `#4FC3E8` |
| כחול כהה (טקסט/כותרות) | `#1A1A6E` |
| גבול רך | `#EDE9F8` |
| ורוד רקע | `#FFF0F7` / `#FFD6EC` |
| גרדיאנט כפתור ראשי | `linear-gradient(135deg, #FF6FB5, #4FC3E8)` |

הטיפ להורה בסוף כל פעילות משתמש בסכמה הצהובה (`#FFF8EC` / `#F5C842` / `#7A5000`),
כמו בפעילויות החינמיות הקיימות.

### נגישות

- `aria-pressed` על כל דבר שנבחר
- `aria-live="polite"` על אזור שמתעדכן אחרי פעולה (תוצאה, מונה)
- `prefers-reduced-motion` — כל אנימציה חייבת מסלול חלופי בלי תנועה
- מטרות מגע של 44px ומעלה. הקלפים והכפתורים עומדים בזה בנוחות

### הדפסה

`Layout.jsx` כבר מגדיר `@media print` שמסתיר `.site-chrome` ו-`.site-decor`
ומנקה את רקע האתר. פעילות שמייצרת פלט להדפסה צריכה רק:

- לסמן ב-`site-chrome` את מה שלא אמור להיות מודפס (כפתורים, קישור חזרה, טיפ להורה)
- להוסיף `break-inside: avoid` לפריטים שאסור שייחתכו באמצע
- לקרוא ל-`window.print()`

## מה במכוון עוד לא נעשה

**אין עדיין "מנוע כרטיסים" משותף.**

לפי המיפוי, מנוע הכרטיסים פותח 6 מכלי גל 0 ו-12 מתוך כל 60 — ולכן מפתה להפשיט אותו מיד.
נמנענו מזה בכוונה: מנוע שנגזר ממימוש אחד הוא ניחוש לגבי מה שיחזור.

במקום זה הופרד התוכן מהרכיב בכל פעילות, כך שההפשטה תהיה זולה כשתגיע.
כרגע יש שני מימושים אמיתיים ושונים — `spin` (גלגל) ו-`pick` (קלפים).
**כשיגיע השלישי** (Coping Cards, במצב build-a-kit) יהיה מספיק דמיון אמיתי כדי
להוציא `shared/` על בסיס מה שחוזר בפועל, לא על בסיס מה שדמיינו מראש.

עד אז, מעט כפילות עדיפה על הפשטה שגויה.
